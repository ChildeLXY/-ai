## 三、方案 A：上传到服务器 + nginx 正式模式

### 1) 上传文件

把 `D:\大肥鱼AI\site\` 下的内容传到 `/var/www/dabaifan/`：

```
index.html          官网首页（本地已修好手机端布局）
404.html            404 页
robots.txt
assets/             char.png / ciallo.jpg / favicon.ico / qr.png / shot-sticker.png
downloads/          可选：dafeiyu-ai-v1.0.0-win64.exe（24MB，见下方注意）
```

Windows 上用 WinSCP / MobaXterm 拖过去即可；或用命令行：

```bash
# 在本机 Git Bash 里执行（把 IP 换成你的）
scp -r "D:/大肥鱼AI/site/." root@<服务器IP>:/var/www/dabaifan/
```

⚠️ **关于 24MB 的 exe**：放在自己服务器上，下载流量走服务器带宽（轻量 3~5Mbps，
一个人下载就要几十秒，多人同时拉会卡死）。建议首页下载按钮指向
`https://gitee.com/liu-xingyuec/dafeiyu-ai-local/releases`（`dist-site/index.html`
就是这么做的），exe 只作为备用。要省带宽就别把 `downloads/` 传上去。

### 2) 切 nginx 到正式模式

用仓库里新生成的干净配置，直接覆盖，不用再注释：

```bash
sudo cp /etc/nginx/conf.d/dabaifan.conf /etc/nginx/conf.d/dabaifan.conf.bak-$(date +%Y%m%d)
# 把 deploy/nginx-dabaifan-正式.conf 上传为 /etc/nginx/conf.d/dabaifan.conf
sudo nginx -t && sudo systemctl reload nginx
```

### 3) 把解析改到服务器

阿里云控制台 → 云解析 DNS → dabaifan.cn → 解析设置：

| 主机记录 | 类型 | 记录值 | 说明 |
|---|---|---|---|
| `@` | A | 服务器公网 IP | 先**暂停/删除**原来那条指向 `dabaifan.cn.w.kunlunle.com` 的 CNAME |
| `www` | A | 同一 IP | 同上，删掉 `www...kunlunle.com` 那条 CNAME |

> 同一主机记录不要同时存在 CNAME 和 A，会冲突；CNAME 的优先级高于 A，留着它 A 永远不生效。

等 10 分钟后验证：

```bash
nslookup dabaifan.cn          # 应返回你的服务器 IP
curl -sI http://dabaifan.cn | head -1        # 期望 200 或 301→https
```

### 4) 签 HTTPS 证书

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d dabaifan.cn -d www.dabaifan.cn
```

certbot 会自动改 nginx 配置并加 80→443 跳转，签完 90 天自动续期。

## 四、方案 B：OSS + CDN　（2026-11-12 选定：走这条）

> **为什么选它**：站点是纯静态 2.6MB、没有后端；OSS 免运维、不用打系统补丁、
> 不用自己续证书；CDN 抗并发（万一被转发到群里，轻量 3Mbps 直接顶不住）。
> 费用：存储 2.6MB 在免费额度内，CDN 内地流量约 0.24 元/GB，这种小站一个月几分钱。
>
> ⚠️ 但先去控制台确认一下：**备案时必须绑定一个阿里云产品**，你很可能已经有一个
> 闲置的轻量/ECS/虚拟主机（已付费）。如果有，走方案 A 更划算，别重复花钱。

### 1) 建 Bucket

| 项 | 填什么 |
|---|---|
| Bucket 名称 | `dabaifan-site`（全局唯一，只能小写字母数字短横线） |
| 地域 | **华南1（深圳）**，离湖南近；或华东2（上海），都属内地 |
| 存储类型 | 标准存储 |
| 读写权限 | **公共读**（静态站必须，否则访客 403） |
| 版本控制 / 加密 | 都关掉，静态站用不上 |

### 2) 开静态页面

Bucket → **数据管理 → 静态页面**：

- 默认首页：`index.html`
- 默认 404 页：`404.html`
- 子目录首页：`index.html`（可留空）

### 3) 上传文件

Bucket → **文件管理 → 上传文件** → 点「扫描文件夹」/「上传文件夹」，
选本机 `D:\大肥鱼AI\dist-site`（8 个文件，2.6MB）：

```
index.html   404.html   robots.txt
assets/char.png  assets/ciallo.jpg  assets/favicon.ico
assets/qr.png    assets/shot-sticker.png
```

传完在 Bucket 里点 `index.html` → 复制文件 URL，先在浏览器打开确认能看，
**这一步不通就别去改解析**。

### 4) 绑自定义域名 + 开 CDN

Bucket → **域名管理 → 绑定域名**：

- 填 `dabaifan.cn`，勾选「**自动添加 CNAME 记录**」和「**开启 CDN 加速**」
- 再绑一次 `www.dabaifan.cn`，同样勾选
- 成功后会给你一个 CNAME 目标，形如 `dabaifan.cn.w.kunlunsl.com`
  （注意是 `kunlunsl` 带 l，不是现在用的 `kunlunle`）

### 5) 改云解析（顺序别错）

在「云解析 DNS」里：

1. **先删** `@` 那条 CNAME（`dabaifan.cn.w.kunlunle.com`）
2. 新增 `@` → CNAME → 步骤 4 给你的 `xxx.w.kunlunsl.com`
3. `www` 同样处理
4. `verification`、`_acme-challenge` 三类 TXT 都别动

> 第 1 步一执行，展示页立刻消失。所以必须在上传完、文件 URL 能打开之后再动。

### 6) HTTPS

CDN 控制台 → 域名管理 → 选中 `dabaifan.cn` → **HTTPS 配置**：

- 证书：点「申请免费证书」（DigiCert 免费版，一年一签，DNS 自动验证）
- 开「**强制 HTTPS 跳转**」
- `www` 同样来一遍

不用 certbot，也不用管续期——到期前控制台会提示，点一下续。

### 7) 刷缓存

CDN → **刷新预热 → 刷新缓存** → 类型选「目录」→ 填 `/` → 提交。
不刷的话可能还在吐旧页面（甚至吐展示页）。

### 8) 成本心里有数

| 项 | 单价 | 这个站大概 |
|---|---|---|
| OSS 存储 | 0.12 元/GB/月 | 2.6MB ≈ **0.001 元** |
| CDN 流量（内地） | 0.24 元/GB | 月访问 1000 次 × 100KB ≈ 100MB ≈ **0.02 元** |
| 请求费 | 几分/万次 | 忽略 |

> 24MB 的 exe **不要**放 OSS：一次下载就是 24MB 流量，还占带宽。
> `dist-site` 版本已经把下载按钮指向 Gitee Releases，就是为这个。

## 八、附：云解析那五条记录，逐条说

> 对照 2026-11-12 阿里云「云解析 DNS」控制台现场截图（dabaifan.cn，TTL 均为 10 分钟）

| 主机记录 | 类型 | 记录值（截断） | 是什么 | 怎么处理 |
|---|---|---|---|---|
| `_acme-challenge` | TXT | `IvC2vByuA9…` | 申请 **SSL 证书**时的 DNS-01 验证令牌，临时写的 | **可留可删**。留着不影响访问；续签时系统会自己换新值，**别手改**，改错了证书续不上 |
| `@` | CNAME | `dabaifan.cn.w.kunlunle.com` | 阿里云**「网站展示页」**的占位解析（就是现在打开的那个 1996 字节空壳） | **改成 A 记录**（填服务器 IP）或 **改成 CNAME**（填 OSS/CDN 加速域名）。改之前先确认站点文件已经就位 |
| `_acme-challenge.www` | TXT | `JzF9ZGp…` | 同上，`www` 那张证书的验证令牌 | 同上 |
| `www` | CNAME | `www.dabaifan.cn.w.kunlunle.com` | 同上，`www` 的占位解析 | 同 `@`，改成和 `@` 指向同一个地方 |
| `verification` | TXT | `wsh_717…` | 阿里云的**域名归属核验**记录（开通解析/证书/CDN 时自动写） | **别动**，删了可能影响证书、CDN 等业务校验 |

**改的时候两个坑**

1. `@` 和 `www` 原记录是 **CNAME**，同主机记录不能再加 A —— CNAME 优先级高于 A，
   留着它 A 永远不生效。所以是「**先删/改那条 CNAME，再加新记录**」，不是"两条并存"。
2. `@` 那条 CNAME 一删，**域名立刻打不开**（展示页也没了）。所以顺序必须是
   **先把站点文件传好、服务跑起来 → 再改解析 → 最后刷 CDN 缓存**。
   反过来操作，访客会看到 502/无法访问，比展示页更难看。

**改完怎么确认（TTL 10 分钟，等 10 分钟后执行）**

```bash
nslookup dabaifan.cn          # 应返回你的服务器 IP，或 CDN 的 CNAME 目标
curl -s https://dabaifan.cn/ | wc -c        # 期望 3 万字节左右；还是 1996 说明没生效
curl -s https://dabaifan.cn/ | grep -o "[^>]*ICP备[0-9]*号-[0-9]"
```

如果 `nslookup` 已经变新 IP 但页面还是旧的，是本地 DNS 缓存或 CDN 缓存，
换个网络（手机 4G）试，或在 CDN 控制台刷目录 `/`。
